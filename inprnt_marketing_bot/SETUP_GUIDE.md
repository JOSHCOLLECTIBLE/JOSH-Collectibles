# 📖 Setup Guide & Organic Sales Playbook

This guide will show you how to deploy your **JOSHSHOOT PRINTS — Multi-Channel Art Marketing Bot** to GitHub Actions so it runs every day **100% free of charge**, and how to use the generated promotions to drive legitimate, high-converting traffic to your shop.

---

## 🛠️ Step 1: Deploy to GitHub Actions (100% Free)

GitHub Actions provides 2,000 free automation minutes per month for public repositories (and 500 for private repositories). Running this bot takes **less than 15 seconds per day** (~7 minutes per month), so it is completely free forever.

### 1. Create a GitHub Repository (or use your existing repo)
1. If you already have **[JOSHCOLLECTIBLE/JOSH-Collectibles](https://github.com/JOSHCOLLECTIBLE/JOSH-Collectibles)**, see `GITHUB_SETUP_JOSH_COLLECTIBLES.md` for exact commands to update it from Step 1!
2. Otherwise, create a repository named `inprnt-marketing-bot` on GitHub.

### 2. Enable Repository Write Permissions for Actions
To allow the bot to commit updated promotion history (`history.json`) back to your repository:
1. Go to your GitHub repository -> **Settings** -> **Actions** -> **General**.
2. Scroll down to **Workflow permissions**.
3. Select **Read and write permissions**.
4. Click **Save**.

### 3. Test Your First Automated Run
1. Go to the **Actions** tab in your GitHub repository.
2. Select **🎨 Daily INPRNT Art Promotion (100% Free Cloud Automation)** from the left sidebar.
3. Click the **Run workflow** dropdown button on the right and click **Run workflow**.
4. Within 20 seconds, your workflow will complete!
5. Click on the completed run and scroll down to **Artifacts** to download your **`daily-inprnt-marketing-pack`** zip file containing your interactive HTML report (`latest_campaign_report.html`) and Pinterest CSV queue.

## 🔔 Step 2 (Optional): Set Up Free Daily Discord or Telegram Alerts

Want your daily ready-to-post marketing copy delivered straight to your phone or Discord server?

### Option A: Discord Webhook (Recommended & Instant)
1. Open your Discord server -> right-click any channel -> **Edit Channel** -> **Integrations** -> **Webhooks**.
2. Click **New Webhook** -> Copy the Webhook URL.
3. Go to your GitHub repository -> **Settings** -> **Secrets and variables** -> **Actions**.
4. Click **New repository secret**:
   - **Name:** `DISCORD_WEBHOOK_URL`
   - **Value:** Paste your Discord webhook URL.
5. Save! Every day at 2 PM UTC, the bot will post an embedded card with the artwork image, price, and copy-paste text directly to Discord.

### Option B: Telegram Bot
1. Open Telegram and search for `@BotFather`.
2. Send `/newbot`, name your bot, and save the **Bot Token**.
3. Create a chat/channel and add your bot.
4. Add two secrets under GitHub repository **Settings** -> **Secrets and variables** -> **Actions**:
   - `TELEGRAM_BOT_TOKEN`: Your BotFather token.
   - `TELEGRAM_CHAT_ID`: Your numeric Telegram Chat ID.

## 📈 Step 3: Organic Art Marketing & Sales Playbook

How to use your bot's multi-channel content to earn sales without spamming or triggering platform bans:

### 1. 📌 Pinterest — The #1 Organic Driver for Art Prints
- **Why Pinterest works:** Pinterest is a visual search engine where users actively search for "wall decor", "art prints", "brutalism photography", and "home aesthetic". Pins remain searchable for months and years.
- **How to use the bot:**
  - Every day (or weekly via `pinterest_bulk_queue.csv`), create a Pin using the high-resolution artwork thumbnail.
  - Use the bot-generated SEO Title (e.g. `JOSH1-222: The Dutch Blue Man | Archival Fine Art Print`).
  - Paste the bot-generated SEO description with keyword hashtags.
  - Set the direct link to your INPRNT gallery item URL.
  - **Pro Tip:** Create 3 Pinterest Boards: *"Architectural Photography Prints"*, *"Phygital Art & Archival Photography"*, and *"Wall Art & Home Decor Inspiration"*.

### 2. 🐦 Twitter / X & Bluesky — Build a Phygital & Collector Community
- **Why it works:** Art collectors, Web3/Phygital art enthusiasts, and photography lovers engage heavily on X and Bluesky.
- **How to use the bot:**
  - Post the short-form "JOSHSHOOT PRINTS • ARCHIVAL RELEASE" showcase with the 20% OFF limited-time discount badge.
  - Once per week, post the **2-Tweet Thread** generated by the bot, which explains the concept behind your series (*"bridging on-chain archives and physical tangibility"*).
  - Engage with other artist hashtags like `#ArtPrint`, `#Photography`, `#ArtCollector`, and tag `@inprnt`.

### 3. 🔴 Reddit — Authentic Artist Etiquette
- **Why it works:** Subreddits like `r/Artstore`, `r/artprints`, `r/photographicprints`, and `r/artcollectors` allow artists to post works for sale.
- **Rules to earn sales on Reddit:**
  - **Never spam:** Only post 2–3 times per week across different subreddits.
  - **Be conversational:** Use the bot's generated markdown template, which includes an "About the Piece & Series" section explaining archival quality and specifications.
  - Respond warmly to any comments or questions about sizing, framing, or international shipping!

### 4. 📧 Email / Substack Newsletter — Retain Your Collectors
- **Why it works:** Email subscribers have the highest conversion rate.
- **How to use the bot:**
  - Use the generated Markdown or HTML newsletter block to send a weekly *"Archival Release of the Week"* feature to your collectors on Substack, Mailchimp, or Buttondown.
